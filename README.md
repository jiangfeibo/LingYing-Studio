# 灵影 Studio · AI 课程制作

**把教学材料变成可观看、可更新的数字人课程。**

一份课件如何成为一节有讲解、有教师画面、有重点引导的课程？教师上传已有材料，说明需要讲解的章节与学生基础，再逐步调整例子、讲稿和课程表达。

**灵影 Studio（LingYing Studio）将材料处理、课程编辑、配音与数字人视频制作连接起来，已有两段完整课堂实例可供观看。** 我们已在源码中实现课件、配音与视频的 Agent 制作接口，将持续讨论、局部改课与素材复用纳入同一套制作能力，让课程随着教材和教学需求一起更新。

## 02 三个核心亮点

### 复用已有教学材料

教师积累的课件与教材可以成为制作起点。系统围绕材料组织讲稿，在已支持的课件结构上安排重点聚焦、激光笔等教学动作，让内容与讲解建立联系。

### 继续编辑课程内容

课程保留可编辑的页面、讲稿和相关素材。对于已支持的页面元素和模板，教师可以修订指定页、调整表达，再安排后续媒体制作。课程更新有明确的内容起点。

### 保存素材，组织视频交付

配音、教师片段和课件画面进入课程制作过程，后台任务保存实际输入与进展，已完成片段可在输入匹配时复用。最终成果可以合成为 MP4，用于离线观看、课程归档与教学展示。

这三个重点共同服务于一件事：**让课程既能交付，也能留下继续制作的基础。**

## 03 课程完成之后，还能继续生长

教材会更新，学生基础会不同，案例也会变化。课程的价值因此不只在第一次生成的视频，还在于内容、声音和媒体素材能否继续使用。

| 使用者与情境 | 怎样使用 | 下一步希望改变什么 |
| :--- | :--- | :--- |
| **教师备课与章节更新** | 复用已有课件，调整讲稿、例子和重点，再制作所需媒体 | 通过对话提出修改要求，减少重复整理和重新录制。 |
| **学生自学与复习** | 观看带讲解、教师画面和内容引导的章节课程 | 为不同基础设计不同解释深度，并保留教师审阅。 |
| **培训与知识维护** | 把已有文档和讲义组织成课程，持续更新变化的内容 | 保留素材与内容关联，让下一版制作沿用已有资产。 |

长期方向是将课件、讲稿、配音与视频积累为课程资产。教师可以围绕某个知识点持续修订，新的媒体模型也可以逐步加入制作能力。这些价值需要编辑、版本与真实输出共同支撑。

## 04 Agent：让课程制作成为持续协作

教师决定讲什么、面向谁、怎样讲得更清楚；Agent 负责将这些要求转化为内容与制作操作。我们已经在源码中实现独立的课件、配音和视频接口，保留通用 Agent 的阅读、讨论、规划与文件操作能力。以下是这套接口所支撑的课程制作方式。

### 理解材料，把教学要求落实到内容

教材、模板、现成课件与参考图片承担不同作用。教师可以在对话中说明：“这份文件作为知识来源，另一份课件参考版式，重点讲清自注意力机制。”Agent 结合当前请求阅读资料、整理讲解重点，再选择需要的制作能力。

材料的用途可以随本次请求调整。相同教材可以面向不同学生组织讲稿；已有课件可以用于直接讲解，也可以成为局部修订的起点。

### 自主安排制作，围绕实际需要选择工具

课件、配音与视频是三项可独立调用的能力。教师只需要讲义时，Agent 可以处理内容与课件导出；教师希望先试听讲稿时，可以直接配音；已有课件和录音时，则可以交给视频接口组织成片。

Agent 围绕目标决定任务顺序，也可以先讨论表达方式，再继续制作。文件整理、内容撰写和错误分析沿用通用能力，专用制作接口承担版式处理、声音合成和视频执行。

### 在同一段对话中继续改课

持续改课从一个具体请求开始：

| 教师的请求 | Agent 的协作方式 |
| :--- | :--- |
| **“换一个更容易理解的例子。”** | 读取已有讲稿，围绕学生熟悉的情境调整解释，再按需更新配音。 |
| **“只修改这两页。”** | 调整指定页面的内容与元素，将修改结果另存，保留原输入和其他已有素材。 |
| **“这段先给我试听。”** | 将选定文字交给配音接口，取得录音后继续讨论节奏和表达。 |
| **“使用我已有的录音。”** | 将现成课件与录音交给视频接口，不要求重新制作声音。 |
| **“沿用上一次的人物素材。”** | 读取保留的任务输入与参考图片，将实际素材用于下一次制作。 |

内容讨论与媒体执行可以分别推进。教师先确认讲解内容，再决定哪些部分需要课件、声音或视频，让每一轮调整服务于教学目标。

### 让后台工作与持续交流并行

配音和视频接口保存实际输入、任务标识、执行状态与输出，Agent 通过任务通知取得进展。在较长的媒体工作期间，讨论和文件编辑仍可继续；重新打开会话时，可以按真实任务标识找回工作。

这些记录也支持有针对性的处理：找到失败步骤，保留已有输出，再决定重试、修改输入或恢复合成。已完成片段只有在实际输入匹配时才复用，课程修改因此能够与媒体更新建立明确关系。

### 交付文件，让成果成为下一轮制作的起点

课件、讲稿、录音和视频以实际文件交付。Agent 可以继续读取这些成果，按教师的新要求修改内容，再组织下一次制作。原稿、满意的录音和人物素材都有机会继续使用，课程由此形成可持续积累的资产。

例如，一门课程先完成基础讲解，随后为基础较弱的学生补充例子，再为复习场景整理简短版本。Agent 协作的价值，是让这些变化围绕已有课程继续展开，把讨论、编辑和制作连接起来。

## 05 下一步：让知识过程动起来

有些知识点需要精确文字，有些则需要看到变化。运动与受力、流动现象、物体交互或生活中的因果情境，都适合探索短场景辅助讲解。

我们计划在可控课件之外，引入类似 MiniMax H3 的生成能力，为某些知识点制作动态素材。例如，讲解一个现象时先展示短场景，再回到课件解释关键变量；讲解一个抽象概念时，用生活情境承接例子，让学生先观察，再理解。

| 教学变化 | 拟采用的做法 | 待验证条件 |
| :--- | :--- | :--- |
| **让过程可观察** | 为合适的知识点生成动态示范片段 | 科学正确性、时间关系与教学相关性。 |
| **让案例有情境** | 用人物与场景承接生活化例子 | 人物连续性、准确讲稿和声音一致性。 |
| **让课程有更多表达选择** | 将短镜头、教师片段和精确课件组织到课程中 | 多片段衔接、局部替换、成本与制作时间。 |

MiniMax H3 官方资料描述了多模态参考与联合音视频生成，单段输出范围为 4–15 秒。因此，长课程需要组织多个短片段；本地 Base 与完整高分辨率流程也存在差异。[MiniMax H3 官方说明](https://github.com/MiniMax-AI/MiniMax-H3)
